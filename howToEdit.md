# Contributing Guidelines

Please follow these steps to make changes.

---

## Overview

- The `main` branch is **protected** — only the project lead can merge code there.
- Everyone should make their own **branch** and submit a **pull request (PR)** when ready.
- You can work directly in the **GitHub web editor** or use **Codespaces** (both are browser-based).

---

## Option 1: Using the GitHub Web Editor (No setup needed)

1. Go to our repo on GitHub.
2. Click the branch dropdown (top-left, usually says `main`).
3. Select **“View all branches” → “New branch.”**
   - Name it something like: `firstname-feature`
4. Click a file to edit → hit the ✏️ (pencil icon).
5. Make your changes and scroll down.
6. Write a short **commit message** (e.g. “Added new word list function”).
7. Select **“Commit directly to firstname-feature.”**
8. GitHub will show a yellow banner:  
   ➜ Click **“Compare & pull request”** → then **“Create pull request.”**

---

## Option 2: Using GitHub Codespaces (Online VS Code)

1. Click the green **“<> Code”** button near the top-right.
2. Open the **Codespaces** tab → click **“Create codespace on main.”**
3. GitHub will open an online coding environment (like VS Code).
4. You can:
   - Edit and run code
   - Make commits
   - Push changes
   - Open pull requests — all with buttons (no terminal needed!)
5. When done, open a **pull request** to have your code reviewed.

---

## 🧭 Before You Start

- Always check that your branch is **up to date** with the latest `main` code.
  - If GitHub says “This branch is behind main,” click **“Update branch.”**
- Don’t edit the `main` branch directly.
- Keep commit messages short but descriptive.

---

## Submitting Your Work

When your feature or fix is ready:
1. Go to the **Pull Requests** tab.
2. Click **New pull request**.
3. Choose your branch → `main`.
4. Add a short title and description.
5. Click **Create pull request.**

This makes sure the correct code is not affected in case a change is incorrect.
