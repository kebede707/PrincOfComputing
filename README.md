## Project Description
This project is a text-based version of the game **Wordle**.  
The player has a limited number of tries to guess a hidden five-letter word.  
After each guess, the program gives feedback on which letters are correct and properly positioned.

## File Overview
- **Wordle.py** – runs the main game loop and handles user input/output.  
- **checkGuess.py** – contains a function that compares the player’s guess to the target word and returns feedback.  
- **wordList.py** – stores or loads the list of possible words that can be chosen as the secret word.  
- **wordlePseudocode.txt** – outlines the program logic and flow for design documentation.
